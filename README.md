## 🚀 Featured Projects

### 🌦️ [Weather Logger — Automated Data Pipeline](https://github.com/junnybonz-dotcom/weather-logger-capstone)

A Python application deployed on an AWS EC2 Ubuntu instance. It retrieves weather data from the Open-Meteo API, stores readings in SQLite, and runs automatically through Linux cron.

**Technologies:** Python, AWS EC2, Linux, SQLite, SQL, Cron, Requests

### ☁️ [AWS Inventory Report — Boto3](https://github.com/junnybonz-dotcom/cloud-engineering-architecture-journal/tree/main/boto3-inventory)

A read-only AWS reporting tool that inventories S3 buckets and EC2 instances using Boto3. Includes AWS identity verification, pagination, and service error handling.

**Technologies:** Python, Boto3, AWS STS, S3, EC2, IAM

### 🖥️ [Log Scanner](https://github.com/junnybonz-dotcom/log-scanner-capstone)

A Python command-line tool that recursively scans directories, inspects file metadata, and summarizes matching error lines in log files.

**Technologies:** Python, Linux, Bash, Filesystem Operations

### 🔗 [API Logger](https://github.com/junnybonz-dotcom/api-logger)

A Python script that retrieves GitHub API data and records timestamped repository statistics in JSON Lines format.

**Technologies:** Python, REST API, Requests, JSON
